# 잉여 농산물 순환 재배분 시뮬레이터

시뮬레이션 기반 잉여 농산물 순환 재배분 최적화 시스템 웹 프로토타입 (2026 동국대학교 공과대학 아이디어 경진대회)

- `index.html` 시나리오 시뮬레이션: 흉작·대풍·수요 급증 등 시나리오에서 Stage 1→2→3→피드백 사이클 반복
  - 바로 열기: `index.html?s=cabbage&run=3` (s = base · cabbage · onion · metro · combo · scaleup)
- `mc.html` 불확실성 시뮬레이션: 생산량·비규격률 불확실성 하 1,000회 몬테카를로
  - 바로 열기: `mc.html?run=1000`
